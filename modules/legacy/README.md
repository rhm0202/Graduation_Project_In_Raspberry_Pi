## motor_module.py

**기존 역할**
`RPi.GPIO` 소프트웨어 PWM 기반 서보 제어 모듈.
- 50Hz PWM 신호를 GPIO 핀으로 직접 출력
- 각도를 듀티 사이클(2.5~12.5%)로 변환해 서보 이동
- 이동 후 0.5초 대기로 목표 위치 도달 확인

**교체 이유**
소프트웨어 PWM 특성상 CPU 부하에 따라 신호가 불안정해 서보 지터 발생.

**대체 모듈**
`modules/motor_module_pigpio.py` (하드웨어 PWM으로 교체)

## motor_module_pigpio.py

**기존 역할**
`pigpio` 라이브러리 기반 하드웨어 PWM 서보 제어 모듈.
- GPIO 핀에 하드웨어 PWM 신호 출력 (소프트웨어 PWM 지터 해결)
- 펄스폭(500~2500μs) 직접 제어
- 단계적 보간 이동으로 부드러운 서보 동작 구현

**교체 이유**
GPIO 핀 직접 제어 방식은 채널 수 제한 및 배선 복잡도가 높음.
PCA9685 I2C PWM 보닛 도입으로 다채널 제어가 용이한 방식으로 전환.
또한 `pigpio` 데몬(`pigpiod`) 별도 실행이 필요해 운영 복잡도 증가.

**대체 모듈**
`modules/motor_module_pca9685.py` (PCA9685 I2C PWM 보닛 방식)
